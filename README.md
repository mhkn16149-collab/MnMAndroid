# MnM Android — الإصدار 1.1

مشروع أندرويد أولي بدون إعلانات أو مكتبات إعلانية مضافة. يتضمن واجهة عربية، تنزيل روابط ملفات HTTP/HTTPS المباشرة، وقائمة تعرض حالة التنزيلات عبر Android DownloadManager.

## البناء
1. افتح مجلد `MnM-Android` في Android Studio.
2. ثبّت Android SDK 35 عند الطلب واسمح بمزامنة Gradle.
3. اختر Run لبناء التطبيق وتثبيته على جهاز Android.

## حدود النسخة الحالية
- هذه ملفات مصدر وليست APK جاهزاً.
- التنزيل يدعم روابط الملفات المباشرة فقط من المصادر التي تسمح بالتنزيل والمحتوى الذي تملك حقه.
- لا يوجد بعد بحث ويب مدمج أو استخراج فيديو من منصات أخرى أو مشغل وسائط داخلي.
- لا يحتوي المشروع على كود أو موارد SnapTube المحمية.
